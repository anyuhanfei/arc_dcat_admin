---
name: handoff
description: 将会话压缩为交接文档，供其他Agent继续工作
---
将当前会话压缩为交接文档，让新的 Agent 可以继续工作。**根据 AGENTS.md 规则 2，保存到项目根目录的 `tmp/` 下**，文件名加时间戳如 `tmp/handoff_20260522.md`。

在文档中包含 "suggested skills" 章节，建议后续 Agent 应调用的技能。

不要重复已在其他产物（PRD、计划、ADR、Issue、提交、Diff）中捕获的内容，通过路径或 URL 引用它们。

隐去敏感信息，如 API 密钥、密码或个人身份信息。

如果用户传入了参数，将其视为下一个会话的重点描述，并据此调整文档内容。

## 输出模板

按以下章节结构生成交接文档，可直接复制套用（替换 `<!-- -->` 注释为实际内容）：

````markdown
# handoff_YYYYMMDD.md — {主题简述}

## 背景与目标
<!-- 本会话要解决什么问题、达成什么目标 -->

## 已完成事项
<!-- 已完成的改动与结论；已捕获在其他产物（PRD、计划、ADR、Issue、提交、Diff）中的内容只给路径或 URL，不重复 -->

## 遗留问题 / 待确认
<!-- 未完成事项、阻塞点、待用户确认的问题 -->

## 下一步建议
<!-- 后续会话建议从何处继续 -->

## suggested skills
<!-- 建议后续 Agent 调用的技能名，如 handoff、systematic-debugging 等 -->

## 敏感信息说明
<!-- 隐去了哪些敏感信息（API 密钥、密码、个人身份信息）及原因 -->
````
